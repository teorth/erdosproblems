# Summary statistics

Aggregate counts over [data/problems.yaml](data/problems.yaml) — how many problems are proved, disproved, open, formalized in Lean, linked to the OEIS, and so on.  Back to the [main page and problem table](README.md).

These counts used to appear at the top of the README.  They were moved here on October 6, 2026, so that a visitor arriving at the repository is not shown a tally of solved problems by default.  This is in accordance with the [policy changes announced at erdosproblems.com](https://www.erdosproblems.com/forum/thread/blog:9) on that date, under which that site no longer displays the statuses of problems, nor the count or percentage of problems solved: the problems are meant to be read as open questions worth understanding rather than as a scoreboard.

The figures are still generated, and the per-problem table on the [main page](README.md) still carries each problem's status, so nothing has been withdrawn from the data — only from the front page.  The [progress chart](README.md#progress) was frozen on the same date for the same reason.

**This page is auto-generated** by [scripts/generate_readme.py](scripts/generate_readme.py) from `data/problems.yaml`.  Do not hand-edit between the markers below; any such edits will be overwritten.
